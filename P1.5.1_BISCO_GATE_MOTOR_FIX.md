# SmartQuote P1.5.1 — Bisco gate-motor identity fix

## Bug
Bisco quotation rows for gate motors contain technical prose such as:

`Khi mất điện mở bằng tay (Có chìa khóa mở kèm).`

The category rule previously treated the standalone word `khóa` as Smart Lock evidence. Because quote-table names can contain the full technical description, TORQ/AYROS/NYK/STAR products could be rewritten as `Khóa thông minh <SKU>`.

## Fix
1. Gate-motor evidence is evaluated before Smart Lock evidence.
2. Standalone `khóa` is no longer enough to infer `Khóa thông minh`.
3. Smart Lock inference requires strong evidence such as `khóa thông minh`, `khóa cửa`, `vân tay`, known lock model families, `door lock`, `smart lock`, etc.
4. Historical quotation cells that contain `product name + Model + technical specs` preserve the first descriptive line as the commercial product name and move the remaining text into `specs`.
5. Pricing, SKU, quote fixed-price semantics and Final/Commercial logic are unchanged.

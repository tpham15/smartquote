# SmartQuote P2.3.4 — PDF Product Identity & Table Parser Hardening

## Scope freeze
P2.3.4 contains no P2.4 feature work. It hardens the existing import pipeline before pilot.

## Root causes fixed
1. `mergePdfRowParts()` treated default `gap=null` as numeric zero, splitting ordinary words inside a description cell into pseudo-columns.
2. Column inference treated embedded numbers such as `1400kg`, `1200kg`, `2200kg` and year `2022` as money evidence.
3. Multi-line PDF headers could be detached from their table region, causing `STT`/price role drift and cross-table header inheritance.
4. Generic contact detection treated any phrase containing `điện thoại` as metadata, dropping real products such as “Thiết bị mở cổng qua điện thoại - Znex”.
5. PDF dedupe could collapse different sellable products when a supplier reused the same code (Roger uses `FU` on 8 distinct products).
6. Sparse price rows with configuration-specific prices were not linked safely to their product row. Roger STT 1/2 now preserve both Đế `201` and `304` price options and require review instead of silently choosing one price.

## Roger golden rules
The release gate locks the supplied 2026 Roger dealer PDF by SHA-256 and requires:
- 88/88 source STT preserved, unique and complete.
- `Mã SP` never substituted for `Thông tin sản phẩm` on ordinary rows.
- `Giá cấp 1` -> `costPrice`; `Giá bán lẻ` -> `listPrice`.
- SMARTY7/R30/G30/T80/Znex critical rows exact.
- 8 distinct `FU` rows preserved.
- STT 1/2 keep two configuration price options (201/304) with no silent price selection.
- supplier notes never leak into catalog products.

## Release policy
This tree is a pilot candidate only after BOTH real-file gates (Bisco XLSX + Roger PDF), full offline regressions and production build pass on the exact committed tree.

## RC2 Pilot gate fixes
- Preserve `documentCategory` / `Quy Cách`, source section, raw SKU and canonical-SKU evidence through canonical preview normalization. This fixes real Bisco XLSX imports losing source taxonomy after extraction.
- In enumerated PDF tables with a strong STT/No. column, reject non-indexed continuation/note rows from product extraction; sparse indexed products are still recovered by the dedicated sparse-row pass.
- Keep commercial price cells separate from immediately-adjacent free-text notes and only accept money-shaped cells for price roles. This protects rows such as Roger LT300/R and G2 where `Giá thu hồi...` appears beside the dealer price.
- Real-file gates now fail cleanly when given a directory rather than a file, and Roger gate prints row diagnostics on count drift.
- No P2.4 features were added; this RC is pilot-hardening only.

## RC3 — merged-cell provenance idempotency
- Bisco real-file gate exposed repeated `Quy Cách` text from merged A13:F13 cells.
- Fixed sheet-context extraction to ignore `_merged` replicas while preserving the top-left source cell and adjacent non-merged metadata.
- No Roger PDF parser or product identity logic changed.

# SmartQuote P1.5 Test Report

## Scope

P1.5 implements Industry-Neutral Core + Workspace Industry Profile on top of the P1.4 Security-Hardened assisted-pilot build.

## Implemented

- Centralized `industryProfiles` config with Generic, Lighting, CCTV, Smart Home, Electrical/MEP and HVAC.
- First-time post-login industry onboarding, plus optional business type.
- Tenant-scoped profile persistence in `dealers`.
- Safe P1.5 Supabase migration preserving P1.4 billing-column restrictions.
- Quote UI neutralized to Product / Section / Product Set terminology.
- Smart Home-only solution-family UI hidden outside Smart Home profile.
- Product editor gains profile-driven optional industry attributes stored in the existing raw product payload.
- Industry-specific import hints and quote-template filtering.
- Global quote-template fallback changed to `minimal_business` so missing/unknown profile state never falls back to Smart Home.
- Settings can change industry without deleting catalog, quote history or Final snapshots.
- Production QA now requires the P1.5 dealer columns.
- Added `smoke:pilot-p15` and updated stale wording/dark-mode smokes for the neutral terminology.

## Environment limitation

The packaging container could not complete `npm ci` because its npm registry/cache was incomplete. Therefore dependency-backed checks (`smoke:quotes`, `smoke:billing` in this environment) and a Vite production build must be rerun on the user's Mac. The previous P1.4 build was proven on that Mac; P1.5 includes exact commands in `PILOT_P1_5_START_HERE.md`.

## Release condition

Do not deploy P1.5 before running `supabase/phase15_industry_profiles.sql` on production. After migration, all `*_should_be_true` values must be `t` and all `*_should_be_false` values must be `f` as described in the start-here file.

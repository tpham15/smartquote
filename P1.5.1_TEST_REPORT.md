# SmartQuote P1.5.1 Test Report — Gate Motor Identity

## Trigger
Historical quotation product descriptions may contain the phrase `Có chìa khóa mở kèm` / `chìa khóa mở khẩn`.
The previous Smart Lock rule accepted the standalone word `khóa`, causing automatic gate motors to be mislabeled as `Khóa thông minh <SKU>`.

## Fix
- Strong automatic-gate evidence now takes precedence over incidental key/lock prose.
- Standalone `khóa` no longer implies Smart Lock.
- Smart Lock still requires strong evidence (smart lock/door lock/fingerprint/known lock model family).
- Quote-table product descriptions preserve the first commercial-name line; model/technical lines move to specs.
- No pricing, margin, billing, Final Quote Gate, revision or tenant logic was changed.

# SmartQuote P2.3.6 RC7 — Identity alias regression hotfix

RC7 is a narrow regression fix on top of RC6. No new importer feature is added.

## Root cause
RC6 correctly rejected natural-language pseudo-SKUs, but the rule also rejected valid historical aliases such as `Vulcan - 24V (29G020)`. That discarded source identity evidence before the old-quote commercial-name recovery path could run.

## Fix
- Preserve mixed commercial-model aliases when they contain a strong alphanumeric canonical code in parentheses.
- Keep RC5/RC6 rejection of natural-language pseudo-SKUs such as `Thẻ từ Mifare 13.56Mhz`.
- Do not change PDF parser, price logic, taxonomy, learning, or engineering rules.

# SmartQuote P1.5.3 — Pilot Release Hardening Test Report

## Scope

P1.5.3 fixes release blockers found during independent review of P1.5.2. It does not change pricing, quote snapshots, Final/Revision lifecycle, tenant ownership, or dealer image override behavior.

## Fixed

### Critical security
- `smartquote_increment_rate_limit(...)`: explicit REVOKE from `anon` and `authenticated`; EXECUTE only for `service_role`.
- `admin_prune_api_logs(integer)`: explicit REVOKE from `anon` and `authenticated`; EXECUTE only for `service_role`.
- `consume_usage_quota(...)`: explicit REVOKE from `anon` and `authenticated`; EXECUTE only for `service_role`.
- Fresh schema and Phase 7 migrations carry the same grants.
- `supabase/phase15_3_pilot_release_hardening.sql` is the live-project migration/verification script.

### Industry neutrality
- Default Python Excel export no longer contains `Giải pháp nhà thông minh` or `TỔNG HỢP CÁC GIẢI PHÁP NHÀ THÔNG MINH`.
- JS SheetJS fallback is also neutral.
- Workspace industry context is passed into default Excel export.
- Non-Smart-Home KTS/takeoff grouping uses source group/category instead of Smart Home solution names.
- Legacy Claude BOM/takeoff prompts no longer hard-code Lumi/Hikvision/example SKUs.
- Generic import examples and registration placeholder no longer use Lumi-specific copy.

### Functional fixes
- 30-row Claude BOM batch budget is dynamic (3k–8k output tokens) instead of fixed 1k.
- Onboarding `Bỏ qua` explicitly saves `business_type = null` even after a previous selection.
- `ErrorBoundary` restored at application root.
- `.env.example` restored with safe placeholders and closed-by-default CORS guidance.
- Missing `benchmarks/pilot-golden/private/.gitkeep` restored so public P1.2 freeze smoke runs correctly.
- Legacy Phase 12.3 and 12.5 smokes updated for P1.5 wording/signature.
- Switching away from Smart Home hides solution families but no longer normalizes stored families to `[]`, preventing accidental data loss on save.

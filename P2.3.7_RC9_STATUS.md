# P2.3.7 RC9 — Taxonomy Regression Contract Hotfix

## Scope
Test-only hotfix. No production parser/importer code is changed.

## Why
The legacy P1.5.1 gate-motor smoke expected every gate product category to be `Cổng tự động`.
P2.3.3 deliberately changed the taxonomy contract: `Cổng tự động` is the broad family, while category remains source-specific (`Cổng trượt tự động`, `Cổng tay đòn tự động`, `Cổng âm sàn tự động`).
The Bisco golden gate and P2.3.3 regression already enforce this newer contract.

## Change
Updated `scripts/pilot-p151-gate-motor-regression-smoke.mjs` to assert the source-specific category per test case.

## Production code
Unchanged.

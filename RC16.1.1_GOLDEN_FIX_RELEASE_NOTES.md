# RC16.1.1 Pilot golden fixture consistency fix

This is the complete RC16.1.1 source with the P1.2 commercial golden fixture lock repaired.

## Root cause

RC16.1.1 intentionally changed two commercial-golden scenarios to allow at-cost and below-cost Final Quotes after user acknowledgement. However, the golden fixture lock still contained the SHA-256 from RC16.1. The smoke test therefore correctly rejected the mismatch.

## Changes

- Bumped commercial golden scenario version from `0.1.0` to `0.1.1` (business-policy change).
- Regenerated the SHA-256 in `commercial-freeze-lock.json` from the updated fixture.
- Added assertion that the scenario fixture and lock have the same version.
- No production pricing or database logic changed in this fix.

## Validation

Run `npm run smoke:pilot-p12`, `npm run smoke:flexible-pricing`, `npm run smoke:pilot:offline`, and `npm run build` before production deployment. Do not bypass failing tests. Verify deployment and Supabase release gates separately.

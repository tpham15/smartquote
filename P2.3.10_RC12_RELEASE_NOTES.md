# SmartQuote P2.3.10 RC12 — Roger Supplier-Code Reuse Gating Hotfix

## Scope
Business-validation + preview gating hotfix only. No PDF extraction, identity parsing, price extraction, taxonomy, or RC11 large-Excel upload logic changed.

## Root cause
Roger's PDF pipeline correctly preserved repeated supplier codes as distinct products and marked them with a warning (`supplier_sku_reused_for_distinct_products`). The later commercial validator then added `duplicate_sku_in_import` as an ERROR simply because the SKU appeared more than once. The preview also treated every warning as unsafe, so a warning downgrade alone would still have excluded those rows from import.

## Fix
1. Same SKU + visibly different product names/configurations => REVIEW/WARNING, never duplicate-SKU ERROR.
2. Same SKU + same visible product name => remains blocking duplicate-SKU ERROR.
3. Grounded supplier-code-reuse warnings remain visible but are explicitly non-blocking/importable.
4. Preview CTA/count uses `willImport`, not only zero-warning `clean` rows.
5. Other warnings/errors remain fail-safe; RC12 does not globally make REVIEW rows importable.
6. Roger real-file gate is extended so legitimate reused codes cannot regress back into blocking duplicate errors.

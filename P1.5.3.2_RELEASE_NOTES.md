# SmartQuote P1.5.3.2 — Product Identity Fix

## Why
Bisco quotation imports could still display every gate product as `Cổng tự động + SKU` even though P1.5.1 already fixed the earlier `Khóa thông minh` misclassification.

The remaining issue was not category inference. The real column profiler treats long `Thông số sản phẩm` cells as specs/name-source, then the old derived-name fallback rebuilt the display name from `category + SKU`.

## Fix
- For quotation tables, when `Thông số sản phẩm` contains a commercial product name on the first line and technical details below, the first line is recovered as `product.name` before derived-name fallback runs.
- `Cổng tự động` remains a broad catalog `category`; it no longer replaces the product's commercial identity.
- Technical text remains in `specs`.
- Existing smart-lock protection remains intact.

## Verified examples from Bisco
- `MÔ TƠ CỔNG TRƯỢT V2 - TORQ - 500D`
- `MÔ TƠ CỔNG TRƯỢT V2 - AYROS - 1000D`
- `Mô tơ cổng Mở xoay tự động NYK - 24V`
- `Mô tơ cổng Mở xoay tự động STAR K3 - 24V`
- `MÔ TƠ CỔNG TRƯỢT AYROS 650`
- `Mô tơ cổng Mở xoay tự động STARK 600 V2`
- `Cổng xoay tự động âm sàn V2 - VULCAN 24V`

## Database
No Supabase migration is required for P1.5.3.2.

Previously imported catalog rows whose names were already saved as `Cổng tự động ...` must be re-imported or manually corrected after deploying the fix.

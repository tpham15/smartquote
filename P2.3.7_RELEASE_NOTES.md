# P2.3.7 RC8 — Remaining Supplier Hardening

RC8 is a narrow pilot-hardening release derived from the Diagnostic v4 corpus.
It does not add product features.

## Root causes addressed

1. Locked/code-only mapped names could block grounded recovery from raw source rows.
2. Fabric/model ranges such as `C007-C008` could outrank a sellable source-leading code such as `C007-MCS`.
3. Feature/configuration tokens (`TAY/PIN`, `TAY/TH`, `IN/CHECK`) and electrical/dimension values could poison SKU identity.
4. Accounting carry-over rows (`Nợ đầu kỳ`, `Nợ phát sinh`, `Nợ cuối kỳ`) could leak into catalog parsing.
5. Rows with a valid sell/list price but no cost/SKU were failed before user review.
6. Early `missing_sku` / `missing_price` issues could remain stale after later grounded recovery succeeded.

## Release rule

RC8 is only a candidate until the user's Mac passes:
- `smoke:pilot-p23.7`
- Bisco real-file golden gate
- Roger real-file golden gate
- full `smoke:pilot:offline`
- production build
- Diagnostic v4 corpus rerun

Scan/image PDFs remain REVIEW by design.

## Additional identity guard

Free-text recovery now accepts compact one-letter-plus-digits model codes such as `A110` while the existing technical-value blacklist continues to reject voltages, dimensions and material grades.

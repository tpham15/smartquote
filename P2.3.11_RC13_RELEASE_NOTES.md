# SmartQuote P2.3.11 RC13 — Commercial Price Safety

Date: 2026-10-31
Base: P2.3.10 RC12 Final Pilot baseline

## Why this hotfix exists

A supplier workbook with one generic column named `Đơn giá`, `Unit price`, or `Price` is financially ambiguous. The value may be supplier cost or an already-sold/list price. RC12 could silently promote this generic column to `costPrice`, which could distort markup, gross margin, and the below-cost Final Quote Gate.

A second pilot UX issue was that a brand-new workspace defaulted to markup ×1.00, so its first cost-based quote showed 0% gross margin and was correctly blocked by the Final Quote Gate.

## Changes

1. Generic single-price columns are REVIEW by default.
   - `Đơn giá`, `Đơn giá (1.000đ)`, `Unit price`, and plain `Price` are not silently treated as supplier cost.
   - Preview blocks catalog save until the user makes one file-level decision.
   - The user can choose `Giá nhập / giá vốn` or `Giá bán / niêm yết`, or change mapping.
   - Choosing list price moves the extracted value to `listPrice/publicPrice`, keeps `costPrice` empty, and records provenance.

2. Deterministic price evidence remains unchanged.
   - Explicit `Giá nhập`, `Giá đại lý`, `Giá cấp 1`, `Cost`, `Dealer`, etc. remain automatic cost mappings.
   - Quote tables with `SL × Đơn giá = Thành tiền` remain fixed-price quote evidence rather than generic supplier-cost inference.

3. New workspace default markup is ×1.20.
   - Existing explicit user/workspace settings, including legacy ×1.00, are preserved and are not silently migrated.
   - Settings explains that ×1.20 is only a starting default and should be adjusted to company policy.

4. Release gate hardening.
   - `smoke:core-review` is now part of `smoke:pilot:offline` and `smoke:pilot`.
   - RC5's historical test was updated to the safer RC13 contract.
   - Added `smoke:pilot-p23.11`.

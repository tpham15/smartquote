# SmartQuote P1.5.2 — Dealer Image Override

## Goal
Serper/web-enriched images are suggestions only. A dealer can click the product thumbnail in Catalog and upload the correct image. Dealer-uploaded images become the preferred product image and are not replaced by automatic image search.

## UX
- Click an existing thumbnail → file picker.
- Click an empty `?` thumbnail → file picker.
- Allowed: JPG, PNG, WebP; max 4MB.
- Uploaded thumbnail gets a green ✓ marker.
- Hover/focus shows `Đổi ảnh` / `Thêm ảnh`.

## Cloud persistence
Cloud workspaces upload images to Supabase Storage bucket `catalog-product-images`.
- public-read: required so generated customer quotations can fetch/embed the product image URL.
- tenant-write: insert/update/delete are restricted to authenticated members of the dealer UUID prefix.
- object path: `<dealer_id>/<product_id>/main.<ext>`.
- replacing an uploaded image removes the prior object when its path changes.

Local/demo mode falls back to a data URL and does not require Supabase Storage.

## Priority rule
`_meta.imageSource = dealer_upload` and `_meta.imageLocked = true` mark a manual dealer override. Serper automatic image fill only targets products without an image and explicitly excludes dealer-upload overrides.

## Required production migration
Run `supabase/phase15_2_catalog_image_overrides.sql` in Supabase SQL Editor before testing cloud image upload.

The final verification query should return `true` for all `*_should_be_true` columns.

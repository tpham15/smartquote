# SmartQuote P2.3.12 RC14 — post-RC13 hardening

Source spec: `SmartQuote RC14 — Spec sửa lỗi sau review RC13.docx`.

## B1 — explicit list price remains list price
- `_meta.priceColumnRole` is authoritative through sanitizer/merge/cloud serialization.
- Role `list`: `costPrice=0`, validates `listPrice`, uses `priceMode=fixed`, never recovers cost from raw text.
- Merge into an existing product updates list/public price but preserves existing positive cost.
- Role `cost` updates cost and leaves existing list price intact.
- Test: `npm run smoke:pilot-p23.12` → `pilot-p2312-price-role-save-path-smoke.mjs`.

## B2 — price-role confirmation removes only price-column uncertainty
- `applyAmbiguousPriceRole` no longer writes `acceptedAtPreview`.
- `price_scale_suspect` remains blocking and scaled values are never replaced with unscaled raw-text recovery.
- Any `error` remains hard even after per-row approval; warnings can still be explicitly approved row-by-row.
- Static guard prevents price-role helper auto-approval.

## M1 — Engineering checks contextual UI
- Lighting-only quote hides the panel completely.
- CCTV/Smart Home or any quote with actual engineering checks shows the panel.
- CCTV storage inputs appear only when a `CCTV_*` rule is active.
- Removed internal `P2.3 / deterministic` customer copy and translated primary rule titles.

## M2 — server-side Final quote immutability + grounded learning
- Added `supabase/phase23_12_final_quote_lock.sql` and merged it into `schema.sql` and root `01_RUN_ON_SUPABASE.sql`.
- Added `finalize_quote(uuid,jsonb)`; cloud client Final now uses this RPC.
- Trigger blocks creating/updating Final via ordinary writes, blocks delete, and permits only sales `status` changes on Final.
- `saveCloudQuote` refuses lifecycle `final`; status updates use a dedicated status-only client path.
- Learning requires server `finalizedBy`, rejects product IDs outside quote rooms, and derives qty/sale/cost/snapshot/finalized time from saved quote content.

# SmartQuote P2.3.3 — Source Taxonomy Preservation

## Why
P2.3.2 correctly separated SKU/Model from product display name, but it still collapsed all Bisco automatic-gate rows into the broad catalog category `Cổng tự động`. The source workbook contains more specific taxonomy and sellable-product terminology.

## Fixed
- `Cổng tự động` is now stored as the broad **family** (`attributes.identity.family`), not forced into every product's category.
- Excel `Quy Cách:` is preserved as `source.documentCategory` provenance and used as stronger category evidence.
- Bisco categories remain specific:
  - `Cổng âm sàn tự động`
  - `Cổng trượt tự động`
  - `Cổng tay đòn tự động`
- Product type follows the source product line instead of being rewritten generically:
  - `Cổng xoay tự động âm sàn`
  - `Mô tơ cổng trượt`
  - `Mô tơ cổng mở xoay tự động`
- Canonical product names preserve source terminology while keeping Model/SKU separate.
- Merge mode continues to repair legacy catalog rows by canonical SKU, then updates category/name/productType without duplicating the product.

## Bisco examples
- VULCAN 24V → `Cổng xoay tự động âm sàn V2 - VULCAN 24V` / category `Cổng âm sàn tự động` / SKU `29G020`
- TORQ 500D → `Mô tơ cổng trượt V2 - TORQ 500D` / category `Cổng trượt tự động` / SKU `30C109`
- NYK 24V → `Mô tơ cổng mở xoay tự động NYK 24V` / category `Cổng tay đòn tự động` / SKU `29H001`

## Data model
`Family != Category != Product Type != Subtype != Model != SKU != Product Name`

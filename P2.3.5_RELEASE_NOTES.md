# SmartQuote P2.3.5 RC5 — Importer Hardening

Feature freeze remains in effect. This release is a supplier-import reliability pass driven by the 10-file supplier regression corpus and ROOT_CAUSE_SAMPLES diagnostics.

## Core fixes

1. **Source commercial name authority**
   - Concise source labels such as `PLAIN`, `CUTIE`, and descriptive product labels now beat the opaque fallback `Sản phẩm <SKU>`.
   - Model/SKU remains separate identity evidence.

2. **Single-source `ĐƠN GIÁ` handling**
   - A workbook with exactly one explicit `ĐƠN GIÁ` / `Đơn giá (VND)` monetary column is no longer marked price-column uncertain solely because the header is generic.
   - Retail/promo/list/tier labels remain review-sensitive.

3. **Natural-language pseudo-SKU guard**
   - A badly labelled `Mã` column containing prose such as `Thẻ từ Mifare 13.56Mhz` is preserved as source product name rather than promoted to canonical SKU.

4. **Tax/subtotal leakage guard**
   - `Thuế`, `VAT`, `Tổng cộng`, `Tạm tính` pseudo-products are blocked from catalog extraction.

5. **PDF name-collapse recovery**
   - If a PDF column model returns the same text for `name` and `sku`, SmartQuote deterministically recovers the description from the grounded row instead of showing `name = sku`.

6. **Diagnostic Gate v3 semantics**
   - Golden PASS remains authoritative.
   - Preserved identity conflicts / reused supplier codes are REVIEW evidence, not automatic corruption failures.
   - Exact duplicates use canonical `productIdentityKey`.
   - PDF STT diagnostics use explicit source STT only; source row index is no longer mistaken for STT.

## Not changed

- Roger PDF column-price logic.
- Bisco XLSX source-taxonomy logic.
- Engineering Rules.
- Learning Memory.
- Scan/image PDF routing remains REVIEW; OCR/vision is not added in RC5.

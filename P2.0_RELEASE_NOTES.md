# SmartQuote P2.0 — Learning Memory Foundation

## Goal
SmartQuote now learns from **Final quotes** as human-confirmed evidence, while preserving the commercial safety rule that historical prices are suggestions only.

## What P2.0 learns
- Confirmed product identity from Final quote snapshots.
- How often a product appears in Final quotes.
- Total quantity quoted.
- Section / hạng mục context.
- Customer category context.
- Historical sale-price samples and margin samples for guidance.
- Existing template-memory and correction-learning layers remain active.

## Confidence tiers
- 1–2 Final quotes: `observe` — store evidence only.
- 3–4 Final quotes: `suggest` — surface memory metadata, do not mutate identity.
- 5+ Final quotes: `trusted` — may fill missing/placeholder **identity fields only**.

P2.0 never auto-applies historical `costPrice`, `listPrice`, or sale price from quote history.

## Cloud persistence
New table: `public.quote_learning_observations`.

Browser clients can read only their tenant-scoped rows through RLS. Writes are only through `record_quote_learning_observations(...)`, which verifies:
- authenticated user;
- membership in the target dealer;
- target quote belongs to that dealer;
- quote workflow lifecycle is `final`.

## UI
When changing a product on a quote line, SmartQuote can show:
- number of Final quotes containing that product;
- total historical quantity;
- median/range historical sale price;
- median historical margin.

The panel explicitly states that history is reference data and does not change the current price.

## Import improvement
The import learning chain is now:

`Correction Learning -> Final Quote Identity Learning -> Sanitizer`

Trusted Final-quote memory can fill weak/missing name/category/unit/brand/origin/specs when the same safe product identity is seen again.

# SmartQuote RC16.1.1 — Flexible Pricing Pilot Patch

- **Policy**: Final Quote allows at-cost and below-cost pricing after human confirmation. Margin stays visible as a warning; no automatic price modification.
- **Per-quote pricing**: A product-line editor now accepts an optional sale-price override for both fixed-price and markup products; catalog and cost prices are unchanged.
- **Markup factor**: individual line factor supports values below 1 (min 0.01); BOM factor can also be below 1.
- **BOM creation**: no longer hard-blocks on markup ≤ 1; asks for confirmation and lets user review the Draft.
- **Safety retained**: missing product, missing/zero sale price, missing cost snapshot, missing customer, invalid VAT, engineering checks and tenant roles remain enforced.
- **Final snapshot**: sale price and cost saved immutably. All warnings are commercial only. Verify backend SQL and production smoke gates before giving users real pilot access.

## Deployment

Apply this as a source update to the existing `~/Downloads/SmartQuote-git` Git repo; do not `git init` or force push. Existing RC16.1 migration remains unchanged. If Vercel is attached to `main`, pushing will deploy to production: test before pushing.

### Important
- Markup at/below cost is intentionally legal at the application rule level. If selling below cost has business, contractual, or regulatory implications, the company must decide them outside this software.
- The rule still rejects zero/negative sale prices, missing cost snapshots, missing products, invalid VAT and unauthorized users.
- Built-in confirmation is a UI acknowledgement; it is **not** a management approval/audit-trail workflow.

# SmartQuote P2.3.9 RC11 — Large Excel Browser Upload Hotfix

## Scope
Browser upload guard only. Importer identity/parser logic is unchanged from P2.3.8 RC10.

## Why
Pilot UAT found a real supplier workbook `Tổng hợp báo giá.xlsx` at 38,854,212 bytes (~37.1 MiB). The deterministic importer could parse it, but the browser rejected it before parsing because the default Excel upload guard was 8 MiB.

## Change
- Default Excel upload limit: **8 MiB → 50 MiB**.
- PDF limit remains **18 MiB**.
- Image limit remains **4 MiB**.
- Excel files above **20 MiB** and up to the 50 MiB limit now show a non-blocking advisory that browser processing can take longer.
- `.env.example` now documents `VITE_SQ_MAX_EXCEL_BYTES=52428800` and `VITE_SQ_WARN_EXCEL_BYTES=20971520`.
- Environment override `VITE_SQ_MAX_EXCEL_BYTES` remains supported; an older `.env`/`.env.local` value can intentionally lower the limit and must be updated for the 37 MiB pilot workbook.

## Safety
Files above 50 MiB still fail closed before XLSX parsing. No supplier parsing, identity, taxonomy, pricing, quote, or PDF logic changed.

## Acceptance
Run:

```bash
npm run smoke:pilot-p23.9
npm run smoke:pilot:offline
npm run build
```

Then repeat browser UAT for the 37 MiB workbook.

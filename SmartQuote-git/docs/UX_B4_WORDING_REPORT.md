# SmartQuote UX B4 — Thống nhất từ ngữ

## Phạm vi

B4 chỉ đổi nhãn hiển thị để thống nhất khái niệm, không sửa logic tính toán/import và không đụng `src/import-engine/**`.

## Đã đổi

- `+ Thêm giải pháp` → `+ Thêm phòng`.
- Phòng mặc định mới là `Phòng 1`; phòng thêm mới là `Phòng 2`, `Phòng 3`...
- Cột phân bổ trong báo giá đổi từ `Khu vực / Phân bổ` → `Phòng / Phân bổ`.
- Các nhãn nhà cung cấp dài hơn ở nơi đủ rộng:
  - `Mở Zalo với NCC` → `Mở Zalo với Nhà cung cấp`.
  - `Chưa có NCC` → `Chưa có nhà cung cấp`.
  - `Tên NCC` → `Tên nhà cung cấp`.
  - `NCC/Brand` → `Nhà cung cấp/Brand`.
  - `Gợi ý NCC` → `Gợi ý nhà cung cấp`.

## Chưa làm

- Chưa làm B5 progressive disclosure.
- Chưa làm B6 cảnh báo preview import nổi bật hơn.
- Chưa làm B7 design tokens.
